## 💻 Cara Menjalankan Portofolio (Offline Mode)

1. Buka folder proyek ini di komputer Anda.
2. Klik ganda pada file `index.html` untuk membuanya langsung di peramban web (Google Chrome, Mozilla Firefox, Edge, dll.).
3. Seluruh aset CSS dan JS telah tersimpan secara offline dalam direktori `css/` dan `js/`, sehingga dapat diakses tanpa koneksi internet.
