Profil & Dedikasi Akademik

Saya adalah seorang mahasiswa program studi Sistem Informasi di Fakultas Teknologi Informasi, Universitas Budi Luhur. Memiliki ketertarikan yang tinggi dalam memahami bagaimana teknologi informasi dapat diimplementasikan untuk menyelesaikan permasalahan nyata dan mendukung efisiensi operasional.

Pendekatan belajar saya berfokus pada praktik langsung (hands-on). Selain mengikuti perkuliahan akademik, saya aktif mengasah keahlian teknis melalui pembuatan proyek mandiri, kegiatan laboratorium ICT, eksplorasi jaringan komputer, manajemen server Linux, hingga dasar-dasar keamanan siber (cybersecurity).

Tujuan utama saya adalah terus berkembang menjadi seorang profesional IT yang kompeten, berintegritas, dan memiliki fondasi teknis yang kuat di bidang pengembangan perangkat lunak dan infrastruktur sistem.

Boarding House Management System (Sistem Manajemen Kos-kosan)

Aplikasi manajemen indekost berbasis Laravel untuk mempermudah operasional pemilik kost dalam mengelola kamar, penyewa, dan transaksi pembayaran.

  • Integrasi sistem QR Code untuk verifikasi identitas / kamar.
  • Pencatatan tagihan pembayaran & laporan keluhan maintenance.
  • Activity log operasional rumah kost.
Laravel PHP MySQL Alpine.js Vite

Sentiment Analysis Google Reviews Project

Proyek analisis data (Data Mining & NLP) untuk mengklasifikasikan sentimen ulasan pengguna Google Reviews menggunakan algoritma Support Vector Machine (SVM).

  • Pengambilan data ulasan (scraping/dataset Google Reviews).
  • Preprocessing NLP menggunakan library NLTK dan Sastrawi (Stopword & Stemming).
  • Ekstraksi fitur teks menggunakan pembobotan TF-IDF.
  • Klasifikasi sentimen (Positif, Netral, Negatif) dengan model SVM.
  • Visualisasi matriks evaluasi (Confusion Matrix & Accuracy).
Python Google Colab NLTK Sastrawi TF-IDF SVM
